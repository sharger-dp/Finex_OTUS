# 🧪 Finex_OTUS — Automation Testing Project

Проект разработан в рамках обучения на курсе OTUS для отработки навыков автоматизированного тестирования.

## 📌 Описание

Цель проекта — протестировать функциональность веб-приложения Finex с использованием автотестов на Python. В процессе были реализованы UI и API тесты с отчётностью и базовыми практиками CI.

---

## 🔧 Стек технологий

- **Язык:** Python 3.10+
- **Фреймворк:** Pytest
- **Браузерное тестирование:** Selenium WebDriver
- **API тесты:** requests
- **Отчётность:** Allure (если используется)
- **Среда запуска:** Docker (опционально)
- **CI/CD:** GitHub Actions / Jenkins (если есть)

---

🚀 Как запустить
Установка зависимостей:
pip install -r requirements.txt

Запуск тестов:
pytest -v tests/

📊 Примеры покрываемых сценариев

Проверка авторизации (валидные/невалидные данные)

Проверка переходов по вкладкам и отображения элементов

Проверка отклика API (код ответа, структура JSON)

Проверка бизнес-логики на уровне интерфейса
